# f4xp1 — мессенджер для гениев

Быстрее молнии, медленее улитки. Самый большой проект который я делал кучу времени. Эксперемент который немножко затянулся. Или как написать мессенджер в соляново с claude, gpt, gemini, deepseek и не сойти с ума(я не смог хвахвах).
Основная философия проекта была в максимальной скорости и оптимизации, я устал от бесконечных electron приложений и захотел сделать нативный мессенджер, но оказалось это немножко трудно сделать.
